## 🚀 Featured Projects

### 1. RecruVex — AI-Powered HR Management System

**Tech:** Next.js 16 · FastAPI · PostgreSQL · SQLAlchemy · Groq

An AI-powered recruitment platform designed to streamline recruitment workflows through a five-stage pipeline.

- Built job-description generation, CV sourcing, candidate filtering, and interview scheduling workflows.
- Designed PostgreSQL data models and FastAPI endpoints with JWT-based role authentication.
- Integrated resume parsing, GitHub candidate sourcing, and automated interview invitations.
- Developed HR and employee interfaces with analytics and report exports.

### 2. Knowva — RAG Knowledge Base Assistant

**Tech:** FastAPI · Python · React · TypeScript · PostgreSQL · pgvector · Docker

A full-stack Retrieval-Augmented Generation application that answers questions using uploaded documents and provides source-grounded citations.

- Implemented document uploads, streaming AI responses, and clickable citations.
- Built hybrid retrieval using pgvector, PostgreSQL full-text search, Reciprocal Rank Fusion (RRF), and optional re-ranking.
- Integrated local and cloud AI providers through a pluggable architecture.
- Added JWT authentication, role-based access control, guardrails, retrieval evaluation, automated tests, and CI/CD.
